# PageRank - CS50 AI

Implementation of Google's PageRank algorithm as part of Harvard's CS50 Introduction to Artificial Intelligence with Python.

## Overview

This project ranks web pages by importance using two approaches:

1. Sampling (Random Surfer Model)
2. Iterative PageRank Calculation

## Concepts Used

* Markov Chains
* Probability Distributions
* Graph Theory
* Recursive Algorithms
* Convergence Algorithms

## Technologies

* Python 3
* Git
* GitHub

## Run

```bash
python pagerank.py corpus0
```

## Sample Output

```text
PageRank Results from Sampling (n = 10000)
```
